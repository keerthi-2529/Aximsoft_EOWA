🧠 About The Project

Project Overview

The Advanced Deep Learning Project - Multi-Class Skin Disease Classification & Diagnosis Platform is an AI-based application developed to classify different types of skin diseases from medical images.

The system uses Convolutional Neural Networks and Transfer Learning architectures to automatically identify skin lesion categories from the HAM10000 dataset.

Dataset Information

  • Dataset: Skin Cancer MNIST - HAM10000
  • Total Images: 10015
  • Number of Classes: 7
  • Image Size: 224 × 224 pixels
Disease Classes
  • Melanoma
  • Melanocytic Nevus
  • Basal Cell Carcinoma
  • Benign Keratosis
  • Actinic Keratosis
  • Dermatofibroma
  • Vascular Lesion
