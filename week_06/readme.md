Advanced Regression Model Comparison & Optimization Platform
 
A Machine Learning web application built using **Flask** to predict house prices and compare the performance of multiple regression algorithms. The project includes data preprocessing, exploratory data analysis (EDA), feature engineering, model optimization, analytics dashboards, and downloadable PDF reports.

 
Features
 
- House Price Prediction
- Multiple Regression Model Comparison
- Exploratory Data Analysis (EDA)
- Feature Importance Visualization
- Interactive Analytics Dashboard
- Downloadable PDF Reports
  - Prediction Report
  - Model Comparison Report
  - EDA Report
- Responsive Bootstrap UI
